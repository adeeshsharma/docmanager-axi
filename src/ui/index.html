    Background service
    
            
    docmanager stops itself automatically after a long period of no activity, so it's fine to just leave it running. To stop it right now instead, for example before shutting down your machine, use the button below. The next time you or an agent runs any docmanager command, it starts itself again automatically.
    
            
            
          
    
        
    

        
    
          
    
            
    What to enter here
    
            
    Any git remote URL you already have push access to. The repository has to exist first (empty is fine) - docmanager pushes to it, it doesn't create it for you.
    
            
      
              
    • git@github.com:you/docmanager-snapshot.git - SSH, the usual choice for a private GitHub/GitLab repo
      • 
              
    • https://github.com/you/docmanager-snapshot.git - HTTPS, works the same way
      • 
              
    • /path/to/a/bare/repo.git - a local or network path, useful for testing or a self-hosted git server
      • 
            
    
            
    For an SSH remote, authentication comes from this machine's own SSH key - use the "Check SSH setup" button to confirm it actually works. For an HTTPS remote, if your machine doesn't already have a credential helper configured, use the access token field above; docmanager sends it only on the actual push/pull request, never stores it anywhere but this machine's own local settings, and never includes it in a snapshot.
    
          
    

          
    
            
    What actually gets pushed
    
            
    
              
    
                
    Included in every snapshot
    
                
      
                  
    • Every version of every tracked document's real content
      • 
                  
    • Each document's full version history and lineage (what supersedes what)
      • 
                
    
              
    
              
    
                
    Never included
    
                
      
                  
    • Where your files actually live on this machine
      • 
                  
    • This setting, or any other local configuration
      • 
                  
    • The local search index (rebuilt automatically after every pull)
      • 
                
    
              
    
            
    
            
    The remote holds your actual document content, so its privacy is entirely up to how you've configured that repository - keep it private unless you mean to share it.
