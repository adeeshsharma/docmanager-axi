docmanager-axi is a published, actively-used npm package (currently v1.2.0) that helps a user track HTML documents as version-lineage "families," the way git tracks commits - content-addressed, git-backed storage, a derived SQLite index, a CLI built on axi-sdk-js, and a local web UI. It ships as a single npm package with no bundler, syncs across machines via a user-provided git remote, and is designed to be driven primarily by a coding agent shelling out to its CLI.

The most recent major feature is folders: a first-class, nested hierarchy for organizing tracked documents, fully independent of a document's synthetic path. It was built end to end (storage, SQLite index support, full CRUD API and CLI, a doctor auto-repair, and four rounds of UI work - a real folder tree, a dropdown menu replacing a type-to-select prompt, a redesigned move-to-folder picker, a collapsible sidebar, and a compact two-row document-detail header with fast custom tooltips) inside an isolated git worktree, merged via PR, and released as part of v1.2.0. Drag-and-drop for folders is the deliberate next piece, not yet started.

This project's own memory moved from a hand-maintained memory-bank/ folder to Memory Intel (.memoryintel/) recently. The move itself surfaced a real gap in Memory Intel (now fixed upstream, released as memoryintel@1.0.2): nothing forced an agent working in a git worktree to actually run memoryintel update before finishing, and even when it did, nothing said to commit .memoryintel/'s own changes - meaning a worktree's memory updates could be silently lost, never reaching the main checkout via the merged PR. Both this project's AGENTS.md and .memoryintel/instructions.md were manually re-synced to the fixed wording, since both are write-once templates that a fresh memoryintel init never touches on an already-initialized project.

Current state is stable and current: full test suite (182 tests) green, docmanager-axi@1.2.0 and memoryintel@1.0.2 both confirmed installed globally on this machine and matching the npm registry's published latest.
